# 服务项目前端原型

基于现有公司管理平台视觉风格实现的服务项目模块前端原型，覆盖工作总览、帮扶关系管理、部门重点工作、项目诉求办理、日报管理、制度改进建议六个一级菜单。

当前版本为 V1.4：帮扶关系按一人一项目直接配置启用/停用，取消审批；部门重点工作说明项目范围由该事项牵头人的有效帮扶关系自动生成，按项目去重并支持分批填写，销项时实时校验全部项目；项目诉求创建即办理中、支持发起人删除，详情以单诉求办理日报替代手工进展；日报按“日期 + 诉求 + 承办人 + 项目”一事一报，取消暂存和校核；制度建议由部门负责人逐人确认后进入企划归档。模块展示名称为“服务项目”。

## 技术栈

- Vue 2.7.16（Options API）
- Vue Router 3.6.5（hash 模式）
- Ant Design Vue 1.7.8（适配 Vue2）
- Moment 2.30.1（日期组件与业务日期）
- xlsx-js-style 1.2.0（Excel 导出）
- Vite 5 + @vitejs/plugin-vue2（构建与本地开发）

## 数据说明

- 业务数据集中维护在 `src/data/seed.js`，首次启动自动初始化。
- 运行状态持久化在浏览器 `localStorage`（键名 `hq_enablement_db_v5`），刷新不丢失。
- V1.4 使用 `schemaVersion: 8` 在同一存储键内自动迁移旧数据：补充人员工号、项目分公司、工作完成时限与执行结构、诉求办理中状态与发起人、单诉求日报、建议确认节点；旧多诉求日报按诉求拆分，未提交记录不伪装为已提交，未关联诉求的历史记录保留只读；帮扶关系 `已生效→启用`、`已失效→停用`，旧草稿/待审批/驳回记录归档只读。迁移不删除既有业务内容，也不通过更换 key 清空用户数据。
- 如需清空并重新初始化，在浏览器控制台执行：

```js
window.__hqResetData()
```

该入口只提供在代码层，页面不展示开发用重置按钮。

## 导出

- 日报管理 → 全部日报：导出当日日报 Excel。
- 日报管理 → 周度汇总：导出周报Excel，按完整自然周统计，人员到岗按人员＋日期去重。
- 其它菜单不提供导出、打印或 PDF 入口；附件1—3仅作为字段与业务口径参考。

## 边界

- 仅前端原型，不包含后端、数据库、真实登录与数据权限。
- 审批为前端申请单和顺序节点操作，不含流程引擎与岗位权限隔离。
- 附件为浏览器内文件名列表，不上传服务器。
- 日报冻结按北京时间自然日次日 00:00 判断；工作日任务按周一至周五生成。
- 日报按单条诉求独立生成，附件4—5按诉求日报输出；周报统计与导出使用完整自然周，人员到岗按人员＋日期去重。
- 重点工作项目落实行由牵头人当前有效帮扶关系自动生成，前端在初始化、重新进入页面及销项提交前执行幂等本地同步；未部署服务端定时任务。
- 附件1—3无页面下载/打印入口，日报/周报 Excel 列序保持原模板。
