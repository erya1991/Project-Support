# 服务项目前端原型 V1.6

总部与基层的帮扶关系驱动重点工作填报和工作日日报。基层诉求、制度改进建议和工作总览共用同一份本地业务数据。项目使用 Vue 2.7、Vue Router 3、Ant Design Vue 1.7、Moment、xlsx-js-style 和 Vite 5。

## 运行与验证

```bash
npm install
npm run dev
```

开发地址为 [本地工作总览](http://127.0.0.1:5173/#/overview)。生产构建、预览及隔离交互回归命令如下。

```bash
npm run build
npm run preview
node scripts/check-interactions.cjs
git diff --check
```

交互回归使用进程内存储和固定的北京时间，覆盖工作日、周末、跨日冻结、历史资格、共享执行记录与审批状态。项目可用命令见 [package.json](package.json)。

## 页面入口

| 页面 | 路径 | 主要操作 |
|---|---|---|
| 工作总览 | `/#/overview` | 点击四组卡片中的数字筛选六个台账页签。点击单号、标题、项目或日报日期查看详情。 |
| 帮扶关系管理 | `/#/relations` | 选择总部人员、对象类型、分公司及部门或项目。编辑和启停都会记录操作人及时间。 |
| 部门重点工作 | `/#/works` | 企划部维护工作事项、查看项目进度和历史执行情况，按当前查询条件导出 Excel。 |
| 我的重点工作 | `/#/works/mine` | 查看本人项目涉及的全部启用事项，填写或编辑共享的项目落实情况及附件。 |
| 日报管理 | `/#/daily` | 我的日报、全部日报、周度汇总。全部日报可修订已提交记录并导出日报，周度汇总可导出所选自然周。 |
| 基层诉求办理 | `/#/appeals` | 全员提交，由主责总部部门经理受理并指派公司内承办人。承办人填报完成情况、日期及佐证，经理批准或退回。 |
| 制度改进建议 | `/#/suggestions` | 全员提交，手选主责总部部门，保留“涉及制度/流程”文本。经理选择改或不改并回复，选择改时可选填计划完成时间。 |

左上角 **切换演示人员** 控制个人视角、发起组织和操作留痕。原型开放全量数据与各业务状态允许的操作。同一演示者可走完整审批流程，详情会显示节点办理人和实际演示操作人。附件在浏览器中保存名称与大小。

## 填报与统计口径

- 一条启用事项覆盖全部有效项目级关系中的项目，按项目 ID 去重。同项目的多名帮扶人员共用执行记录。首次填报人和时间保留，后续编辑更新最后修改人和时间。
- 事项详情显示已填写项目数／当前有效项目数。总览按“事项＋项目”统计。个人页按事项计数，一项工作在本人的全部项目填完后才计为已填事项。
- 停用事项或项目最后一条有效关系会移出当前任务和统计范围。已填内容保留在事项详情中，重新启用后沿用原记录。
- 北京时间周一至周五，有有效项目级关系的总部人员每天应填一份日报。待填是根据关系推算的视图，首次提交才保存。多个项目及分公司在同一份日报中展示，每个正文字段填一次。项目和组织保存提交时的快照，次日冻结，管理员修订保留原因及前后值。
- 部门级关系计入帮扶关系统计。仅有部门级关系的人员，本原型暂不生成日报任务，正式业务口径待确认。
- 日报及周报 Excel 沿用原附件 4、5 的工作表、列序、合并规则、行列尺寸和样式。多项目共用原“项目”列，周报合并区内不同日期的手录需求按日期换行。周度到岗按人日去重，诉求办结统计使用经理实际批准日期。

## 本地数据与验收示例

浏览器使用 `localStorage` 的 `hq_enablement_db_v5` 键保存业务数据。V1.6 对应 `schemaVersion: 9`。**首次打开已有旧版缓存的地址时，会用 V1.6 样例替换本模块旧数据，包括旧版手工录入记录。** 此后刷新保留当前业务数据。当前演示人员保存在该标签页的 `sessionStorage` 中。

1. 初始人员林致远关联华东分公司的无锡深南电路和西南分公司的綦江江苏省人民医院。进入「我的重点工作」，打开无锡深南电路的一条记录。切换为同样帮扶该项目的吴启明，可查看和编辑同一条记录。
2. 在工作日切回林致远，打开「我的日报」。两个项目及分公司均有展示；关闭窗口后仍待填，提交后显示一份已填，按任一项目均可在全部日报中查到。
3. 切换为项目工程师徐诺，新增基层诉求时会自动带出华东分公司和无锡深南电路；切换为总部人员发起时，可自行选择分公司与部门或项目。
4. 点击总览的「有效部门级帮扶」或「今日应填报人数」检查明细。后者包含具备资格但尚未提交的人员。
